🏥 智能医疗报销系统
一个基于 PHP + MySQL 的智能化医疗报销管理平台，支持用户在线申请报销、智能审核规则引擎、管理员后台审批等功能。系统通过预设的审核规则自动校验报销申请的合规性，大幅提升医疗报销审核效率。

✨ 功能亮点
患者端功能
🔐 用户注册 / 登录 / 退出（支持 Cookie 7 天免登录）

📋 智能报销申请表单（身份证实时验证、日期逻辑校验）

📎 多类型文件上传（发票图片、病理报告等，支持格式与大小限制）

🔍 我的申请记录查看（支持搜索、分页）

📊 可报销疾病目录展示（4 大类，含报销比例说明）

🎯 智能审核引擎自动检测（发票完整性、日期逻辑、金额匹配、病种材料等）

管理员/审核员功能
👤 独立后台登录入口

📝 待审核申请列表查看

✅ 一键审核通过/拒绝

🔎 全部申请搜索与分页浏览

📈 统计卡片展示（总数、各状态数量）

💬 规则引擎管理（支持增删改查审核规则）

🛠 技术栈
后端
PHP 7.4+（原生 PDO 数据库操作）

MySQL 5.7+（InnoDB 引擎，支持 JSON 字段）

Session + Cookie 双会话技术

password_hash() 密码加密（Bcrypt 算法）

前端
Bootstrap 5.3（响应式布局）

Font Awesome 6（图标库）

原生 JavaScript（表单验证、文件类型校验）

验证码（图形验证码）

文件上传
支持格式：JPG、PNG、PDF、DOC、DOCX

大小限制：发票 ≤5MB，病理报告 ≤10MB

MIME 类型双重验证（前端 + 后端）
